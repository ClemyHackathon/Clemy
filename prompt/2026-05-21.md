# 클레미 (Clemy) — 해커톤 예선 프로토타입

> 산업현장의 클레임을 AI로 분석해 분류·원인 후보·대응 방안까지 한 번에 제공하는 서비스

---

## 프로젝트 개요

**서비스명:** 클레미 (Clemy)  
**핵심 가치:** 제조업 현장 클레임을 AI가 자동 분류하고, 반복 원인 패턴을 찾아 빠른 대응  
**타겟 사용자:** CS 담당자 / 품질관리팀 / 납품업체

---

| 레이어 | 기술 | 이유 |

## 핵심 기능 & 서비스 플로우

### 1. 클레임 접수 (CS 담당자)
- 자유 텍스트 입력 + 발생시간, 공정명, 납품업체 선택
- 제출 시 Spring `/api/claims` 호출 → Gemini 분석 → DB 저장 → 결과 반환

### 2. AI 자동 분석 (GeminiService)
Gemini에게 요청하는 내용:
- **클레임 유형**: 소음 / 냄새 / 진동 / 품질불량 / 납품지연 / 기타
- **심각도**: 낮음 / 중간 / 높음
- **원인 후보** 3가지 (우선순위 + 신뢰도)
- **대응 방안** 3가지 (즉시/단기/장기)
- **반복 패턴 여부** (DB 최근 클레임 컨텍스트 포함)
- **한 줄 요약**

### 3. 클레임 목록 & 상태 관리
- 유형별/상태별/납품업체별 필터
- 상태: `접수됨 → 처리중 → 완료`

### 4. 대시보드 (품질관리팀)
- 클레임 유형별 빈도 차트
- 반복 패턴 알림
- 납품업체별 현황

## DB 스키마

Supabase에서 아래 SQL 실행:

```sql
create table suppliers (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  contact_email text
);

create table claims (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz default now(),

  -- 입력
  raw_text text not null,
  occurred_at timestamptz,
  process_name text,
  supplier_id uuid references suppliers(id),

  -- AI 분석 결과
  claim_type text,                   -- 소음/냄새/진동/품질불량/납품지연/기타
  severity text,                     -- 낮음/중간/높음
  root_cause_candidates jsonb,       -- [{"rank":1,"cause":"...","confidence":"높음"}]
  recommendations jsonb,             -- [{"action":"...","priority":1}]
  is_repeated boolean default false,
  ai_summary text,

  -- 처리
  status text default '접수됨',      -- 접수됨/처리중/완료
  notes text
);

-- 샘플 납품업체
insert into suppliers (name) values ('A업체'), ('B업체'), ('C업체');
```

### GeminiService.kt
```kotlin
@Service
class GeminiService(
    @Value("\${gemini.api-key}") private val apiKey: String
) {
    private val client = WebClient.builder()
        .baseUrl("https://generativelanguage.googleapis.com/v1beta")
        .build()

    fun analyzeClaim(
        rawText: String,
        processName: String?,
        supplierName: String?,
        recentClaims: List<String> = emptyList()
    ): ClaimAnalysisResult {

        val contextPart = if (recentClaims.isNotEmpty())
            "\n최근 유사 클레임(참고):\n${recentClaims.joinToString("\n")}"
        else ""

        val prompt = """
            당신은 제조업 현장 클레임 분석 전문가입니다.
            아래 클레임을 분석하고 반드시 JSON만 응답하세요. 마크다운 불필요.

            클레임: $rawText
            공정명: ${processName ?: "미상"}
            납품업체: ${supplierName ?: "미상"}$contextPart

            {
              "claim_type": "소음|냄새|진동|품질불량|납품지연|기타",
              "severity": "낮음|중간|높음",
              "root_cause_candidates": [
                {"rank": 1, "cause": "...", "confidence": "높음|중간|낮음"},
                {"rank": 2, "cause": "..."},
                {"rank": 3, "cause": "..."}
              ],
              "recommendations": [
                {"action": "즉시: ...", "priority": 1},
                {"action": "단기: ...", "priority": 2},
                {"action": "장기: ...", "priority": 3}
              ],
              "is_repeated": false,
              "ai_summary": "한 문장 요약"
            }
        """.trimIndent()

        val body = mapOf(
            "contents" to listOf(mapOf("parts" to listOf(mapOf("text" to prompt)))),
            "generationConfig" to mapOf("responseMimeType" to "application/json")
        )

        val response = client.post()
            .uri("/models/gemini-2.0-flash:generateContent?key=$apiKey")
            .bodyValue(body)
            .retrieve()
            .bodyToMono(Map::class.java)
            .block()

        val text = extractText(response)
        return ObjectMapper().readValue(text, ClaimAnalysisResult::class.java)
    }

    private fun extractText(response: Map<*,*>?): String {
        val candidates = response?.get("candidates") as? List<*>
        val content = (candidates?.firstOrNull() as? Map<*,*>)?.get("content") as? Map<*,*>
        val parts = content?.get("parts") as? List<*>
        return ((parts?.firstOrNull() as? Map<*,*>)?.get("text") as? String) ?: ""
    }
}
```

## Frontend 핵심 코드

### lib/api.ts
```typescript
const API = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:8080";

export async function submitClaim(data: {
  rawText: string;
  processName?: string;
  supplierId?: string;
  occurredAt?: string;
}) {
  const res = await fetch(`${API}/api/claims`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(data),
  });
  return res.json();
}

export async function getClaims(params?: {
  claimType?: string;
  status?: string;
  supplierId?: string;
}) {
  const query = new URLSearchParams(params as Record<string, string>);
  const res = await fetch(`${API}/api/claims?${query}`);
  return res.json();
}

export async function getDashboard() {
  const res = await fetch(`${API}/api/dashboard`);
  return res.json();
}
```

## 데모 시나리오 (발표용 흐름)

1. CS 담당자가 "3공정에서 이상한 소음이 계속 납니다. A업체 납품 부품 설치 후부터 생긴 것 같아요" 입력
2. AI 분석 → **소음** 분류 + 원인 후보(부품 불량, 설치 불량, 마모) + 대응 방안
3. 품질관리팀 대시보드에서 소음 클레임이 최근 3주 연속 증가 중임을 차트로 확인
4. A업체 납품업체 담당자가 본인 업체 관련 클레임 목록 및 개선 요청 확인
